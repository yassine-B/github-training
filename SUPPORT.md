
# Support

Thank you for using GitHub Deep Dive Training.

## Documentation

Visit our documentation website:

<https://yassine-B.github.io/github-training/>

## Questions

For questions about lessons and exercises:

- Open a GitHub Discussion if Discussions are enabled.
- Check existing Issues before creating a new one.
- Provide the lesson number and a clear description.

## Bug Reports

If you discover an error in a lesson:

1. Identify the affected lesson.
2. Explain the incorrect information.
3. Provide the expected correction.
4. Include relevant screenshots or examples.

Use the Bug Report issue template.

## Feature Requests

Use the Feature Request issue template.

## Security Issues

Do not report security vulnerabilities publicly.

Follow the instructions in SECURITY.md.
