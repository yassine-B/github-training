
# Code of Conduct

## Our Commitment

GitHub Deep Dive Training is a learning environment
focused on collaboration, technical knowledge sharing,
and practical software development.

We are committed to providing a welcoming and respectful
environment for everyone participating in the project.

## Expected Behavior

All participants are expected to:

- Be respectful and professional.
- Communicate constructively.
- Respect different experience levels.
- Provide helpful and actionable feedback.
- Accept constructive criticism.
- Focus discussions on technical and educational topics.
- Respect the work and contributions of others.
- Give appropriate credit to original authors.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or discrimination.
- Personal attacks or insulting language.
- Intimidation or threatening behavior.
- Publishing private information without permission.
- Deliberately disrupting discussions.
- Trolling or repeatedly posting irrelevant content.
- Plagiarism or misrepresenting another person's work.

## Collaboration Guidelines

### Issues

When opening an issue:

- Use the appropriate issue template.
- Describe the problem clearly.
- Include reproduction steps when relevant.
- Avoid unnecessary personal comments.

### Pull Requests

When submitting a pull request:

- Explain the purpose of your changes.
- Keep changes focused.
- Provide relevant testing information.
- Respond respectfully to review comments.

### Discussions

When participating in discussions:

- Stay on topic.
- Explain technical disagreements with evidence.
- Avoid hostile or personal language.
- Help other learners when possible.

## Enforcement

Project maintainers are responsible for interpreting
and enforcing this Code of Conduct.

Depending on the severity of the behavior, maintainers
may:

1. Request that inappropriate behavior stop.
2. Remove inappropriate content.
3. Restrict participation in discussions.
4. Close contributions that repeatedly violate these rules.
5. Restrict participation in the project.

## Reporting

Report unacceptable behavior privately to the project
maintainers through the contact method documented in
the repository's SECURITY.md or another designated
private reporting channel.

Do not publish private personal information in issues
or discussions.

## Scope

This Code of Conduct applies to:

- GitHub Issues.
- Pull Requests.
- GitHub Discussions.
- Repository contributions.
- Project-related communication spaces.
