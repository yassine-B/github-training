# Git Branching Guide

## Why use branches?

Branches isolate work so that features and fixes can be developed
without directly changing the main branch.

## Recommended workflow

1. Start from an updated main branch.
2. Create a branch for your task.
3. Make focused changes.
4. Commit your changes.
5. Push the branch to GitHub.
6. Review and merge the changes.

## Commit Best Practices

- Make each commit focused.
- Use descriptive commit messages.
- Follow Conventional Commits.
- Review staged changes before committing.
- Avoid committing generated files and secrets.
