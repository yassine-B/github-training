# Git Fundamentals

## What is Git?

Git is a distributed version control system.

## Important Concepts

- Repository: A project tracked by Git.
- Commit: A recorded snapshot of changes.
- Branch: An independent line of development.
- Merge: Combining changes from different branches.
- Remote: A repository hosted elsewhere, such as GitHub.

## Common Commands

| Command | Purpose |
|---|---|
| git status | Inspect working tree |
| git add | Stage changes |
| git commit | Record changes |
| git branch | List branches |
| git switch | Switch branches |
| git merge | Merge branches |
| git push | Publish commits |
| git pull | Fetch and integrate changes |
