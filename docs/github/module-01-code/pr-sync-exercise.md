# Synchronizing a feature branch with main

## Exercise

 Create a feature branch.

Push it.

Add a second commit to main using a separate documentation branch and Pull Request.

Return to the feature branch.

Run git fetch origin.

Inspect the branch history.

Merge origin/main into your feature branch.

Push the synchronized branch.

Inspect the Pull Request.

You should see the latest main changes reflected in your feature branch.

Merge the feature branch with main .
